# Pilaude Intent

日期：2026-10-16。来源：本次用户访谈；关联 [Spec](2026-10-16-pilaude-spec.md) 与 [Plan](../plans/2026-10-16-pilaude.md)。

## 产品意图

Pilaude 是面向开发者与熟悉 AI 工具的专业用户、公开发布的本地桌面通用工作智能体。用户围绕项目委托代码、文件、研究和内容任务；Pi 提供真实执行能力，界面以每个组件的视觉、布局、动效与操作均和 Windows 当前稳定版 Claude Desktop 一模一样为最高 UIUX 目标，并让任务进展、权限、结果与恢复状态清楚可见。

“原生体验”需要窗口、菜单、文件对话框、托盘、通知、快捷键、输入法与进程生命周期共同成立；它不是只更换颜色，也不意味着必须使用原生控件绘制全部内容。

## 希望形成的使用习惯

用户打开项目，说明目标与验收标准，选择模型并提交任务。智能体可以分派子任务、操作受控浏览器、调用经过授权的工具；用户随时查看进展、介入、停止或调整方向。可交付物留在项目中，关键执行与授权记录可回查。重复工作可以保存为定时任务，在应用运行期间执行。

## 成功标准

1. 新用户能在安装后通过内置引导接入自己的模型，完成一次真实任务，无需另开终端启动后台服务。
2. 编程、资料研究、文档/内容、浏览器操作、多代理和定时任务均有真实可重复的端到端验收。
3. 每个组件均有同版本 Windows 参考、实现截图/差异图与交互对照；覆盖输入法、滚动、焦点、窗口缩放、长会话和深浅色状态。有可见差异或证据缺失时不标为复刻通过；不使用示例中的假执行结果冒充内核状态。
4. 权限决定在执行前生效，取消可传播到子任务和受控浏览器，退出后没有 Pilaude 遗留执行进程。
5. 正式发布通过 Spec 中的 Windows 安装、升级、恢复、兼容性及签名门槛；未满足时标为开发构建。

## 明确不进入首发的范围

Pilaude 云账号、托管模型计费、云会话同步、企业组织管理、移动端、Linux 正式支持、macOS 正式发布、自建插件商店，以及应用已退出时仍执行任务的系统后台服务。

保留上游已经可用的能力；这些非目标不要求删除既有兼容代码。子代理的可控并行不承诺无限递归、自组织团队或跨机器协同。浏览器操作不包含绕过网站登录、验证码或付费限制。

## 授权与执行方式

用户要求一次访谈后写好 intent/spec/plan 再开工。文档先完成并检查，之后在 `fusion/pi-claude-desktop` 开发；例行实现判断由工程方作出并记录，不为每个工作包重复索取许可。购买证书、消费模型额度、使用真实第三方账号、对外发布及不可逆操作仍需相应真实凭据或明确授权。

Spec 中标记为 E 的数值、边界和架构是工程默认值，可调整；它们不冒充用户逐项确认的要求。正式发布条件与本轮已完成事项必须分开报告。
