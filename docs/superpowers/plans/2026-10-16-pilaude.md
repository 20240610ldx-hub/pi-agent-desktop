# Pilaude Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking. 本轮由主执行者在现有融合分支实施；独立审查用于发现设计与变更缺口，不默认并行改动相同文件。

**Goal:** 将 Pi 的真实执行能力与逐组件对齐 Windows 当前稳定版 Claude Desktop 的视觉和交互融合为面向专业用户、Windows 优先的 Pilaude 正式桌面产品。

**Architecture:** 沿用 Tauri + React/Next.js + 本地 Node/Pi 服务；UI 参考按模块适配。授权在后端工具执行入口落实；受控 Chromium 与应用 WebView 分离，子代理和调度器共享执行与权限边界。

**Tech Stack:** 当前锁文件中的 Pi SDK、React 19、Next.js 16、Tauri 2、Rust、Node；浏览器适配使用与锁定 Playwright 版本匹配的 Chromium。新依赖仅随所属任务引入。

**Spec:** [2026-10-16-pilaude-spec.md](../specs/2026-10-16-pilaude-spec.md)。[Intent](../specs/2026-10-16-pilaude-intent.md)。

## Global Constraints

- 用户确认范围 I01–I15 均属正式首发要求；阶段验收用于实施排序，不削减最终范围。I04 以逐组件一模一样为最高 UIUX 目标；本轮锁定 Claude Windows 2.42304.0。
- 优先采用 open-claude-ui 实物资产与交互理念；[逐组件审计](../../pilaude-ui-parity.md) 是资源覆盖和差异记录。参考/实现/差异图与交互证据齐全后才可标为一致性通过；所有已实现界面也须重验。
- Windows 10 22H2 x64 / Windows 11 x64；macOS 兼容架构保留，正式发行随后验收。
- Pilaude；`pilaude`；`io.github.20240610ldx-hub.pilaude`；自有发行仓库 `20240610ldx-hub/pilaude`（2026-10-18 用户授权建立独立公开产品仓库；两个上游 fork 保留用于同步）。
- 本地优先；简体中文与英文完整；MIT 与上游署名保留。用户已另行授权使用其 DeepSeek 官方凭据实测运行时 UI，付费测试仅用 deepseek-flash；采用少量、短输出调用，其余回归使用本地夹具。密钥仅通过进程内存注入，不写文件、日志或提交。
- 不直接修改两份上游 CSS 基线；不将 Electron 入口导入 Tauri renderer；不静默重命名 npm / Rust 上游包。
- 干净开发构建与正式签名发行分开；不使用原作者更新信任链。
- 显式退出后无后台任务；敏感副作用必须经过执行前授权；第三方任意本地代码不冒充受 OS 沙箱隔离。
- 测试和构建日志进入 `test-results/pilaude/`；不得把未运行项目记为通过。
